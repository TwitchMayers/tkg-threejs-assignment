# ТКГ — Three.js Assignment

## Текущее состояние

Реализованы **Части 1 и 2** задания.

## Запуск

```bash
npm install
npm run dev
```

Открыть:
- `http://localhost:5173/`
- `http://localhost:5173/parts-1-3.html`

## Выполнено

### Часть 1
- Сцена с `OrbitControls`.
- Включены тени.
- Используется текстурированный меш.
- 3+ источника света, минимум 2 типа.
- 4+ объектов, включая 2 объекта на `BufferGeometry`.
- HTML-управление параметрами сцены.

### Часть 2
- Добавление пользовательских моделей через `input[type=file]`.
- Добавление через drag-n-drop.
- Поддержка `.obj` и `.glb`.
- Выбор модели: кликом по сцене и через список.
- Трансформации через `TransformControls` (move/rotate/scale).
- Числовые поля для позиции / поворота / масштаба.
- Поворот вводится и отображается в градусах.
