# ТКГ — Three.js Assignment (Части 1–4)

Демонстрация (GitHub Pages):
- https://twitchmayers.github.io/tkg-threejs-assignment/

## Запуск локально

```bash
npm install
npm run dev
```

Страницы:
- `http://localhost:5173/` — навигация.
- `http://localhost:5173/parts-1-3.html` — части 1–3.
- `http://localhost:5173/part-4.html` — часть 4.

## Проверка соответствия ТЗ

### Часть 1
- Есть сцена с навигацией камеры через `OrbitControls`.
- Включены тени.
- Есть меш с текстурой изображения (`checker.svg`).
- Есть не менее 3 источников света, минимум 2 типа.
- В сцене не менее 4 объектов.
- Минимум 2 объекта созданы с использованием `BufferGeometry` (плоскость + треугольная пирамида).
- Используются стандартные HTML элементы ввода для управления параметрами сцены.

### Часть 2
- Добавление моделей через `input[type=file]`.
- Добавление моделей через drag-n-drop.
- Выбор модели доступен двумя способами:
  - клик по объекту на сцене;
  - выбор в списке объектов.
- Выбранную модель можно перемещать / поворачивать / масштабировать (`TransformControls`).
- Есть числовые поля для позиции / поворота / масштаба.
- Поворот отображается и задается в градусах.

### Часть 3
- Есть видимый GLSL-эффект на пользовательском шейдере, включен по умолчанию.

### Часть 4
- Удалены демонстрационные объекты, отдельная страница работает как 3D-визуализатор sRGB в CIELAB (D65, 2°).
- Есть подписи осей `L`, `a`, `b`.
- Граница пространства sRGB отображается сеткой точек с шагом 5.
- Отображаются добавленные пользователем точки.
- Пользователь может добавить максимум 4 точки sRGB через поля ввода и кнопку.
- Добавленные точки можно перемещать.
- Для всех пар добавленных точек строятся линии и выводится таблица `ΔE76`.
