# ТКГ — Three.js Assignment

## Текущее состояние

Реализованы **Части 1, 2 и 3** задания.

## Запуск

```bash
npm install
npm run dev
```

Открыть:
- `http://localhost:5173/`
- `http://localhost:5173/parts-1-3.html`

## Выполнено

### Часть 1
- Сцена с `OrbitControls`.
- Включены тени.
- Используется текстурированный меш.
- 3+ источника света, минимум 2 типа.
- 4+ объектов, включая 2 объекта на `BufferGeometry`.
- Есть HTML-управление параметрами сцены.

### Часть 2
- Добавление пользовательских моделей через `input[type=file]`.
- Добавление через drag-n-drop.
- Выбор модели кликом по сцене и через список.
- `TransformControls` для перемещения/поворота/масштаба.
- Числовые поля трансформаций, поворот в градусах.

### Часть 3
- Видимый GLSL-эффект по умолчанию (пользовательский шейдер на сцене).
